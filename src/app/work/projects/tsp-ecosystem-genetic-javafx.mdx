## Contexte et objectif

<Text align="justify">
Le projet part d’un énoncé classique — le voyageur de commerce (TSP) — appliqué à un <strong>écosystème académique</strong> (personnes, disciplines, villes, régions). L’objectif : modéliser cet écosystème, <strong>charger les villes</strong> et leurs attributs, puis <strong>optimiser une tournée</strong> (cycle hamiltonien) à l’aide d’un <strong>algorithme génétique</strong> (sélection proportionnelle à la fitness, crossover, mutation, élitisme).
</Text>

## Fonctionnalités principales

<ul>
  <li>Paramétrage GA : taille de population, probabilité de mutation, élitisme, itérations.</li>
  <li>Critères écosystème : sélection de personnes par discipline/rôle, mappage vers les villes.</li>
  <li>Simulation TSP : génération → sélection → crossover → mutation → élitisme → convergence.</li>
  <li>Interface JavaFX : critères, paramètres, lancement, meilleurs itinéraires, export.</li>
  <li>Règles de saisie : villes en <strong>MAJUSCULES</strong> dans l’UI (cohérence avec les données).</li>
</ul>

<Text align="justify">
Le moteur d’algorithme génétique est <strong>réutilisable</strong> : les opérateurs (crossover/mutation) sont interchangeables et le cœur peut servir à d’autres problèmes d’optimisation sans impacter l’UI ni la persistance.
</Text>

## Points techniques notables

<ul>
  <li><strong>Sélection proportionnelle</strong> : tirage pondéré, favorisant les cycles courts.</li>
  <li><strong>Crossover TSP</strong> (cycle) : combine deux parents tout en préservant la validité de la permutation.</li>
  <li><strong>Mutation swap</strong> : permutation aléatoire de deux villes pour maintenir la diversité.</li>
  <li><strong>Élitisme</strong> : conservation d’un pourcentage des meilleurs individus.</li>
</ul>

## Résultats et apprentissages

<ul>
  <li>Amélioration par rapport aux heuristiques simples (ex. nearest neighbor) sur jeux de test.</li>
  <li>Convergence reproductible via seed + élitisme ; compromis qualité/temps via paramètres.</li>
  <li>Renforcement pratique : <strong>POO Java</strong> (génériques), <strong>JavaFX</strong> (UI), <strong>JDBC</strong> (accès données), <strong>JUnit5</strong> (tests).</li>
</ul>
