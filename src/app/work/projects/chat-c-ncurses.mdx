## Objectif du projet

<Text align="justify">
Ce projet universitaire visait à développer une application de messagerie temps réel en ligne de commande, permettant à plusieurs clients de communiquer via un serveur TCP.  
L’enjeu principal était d’illustrer la gestion concurrente en C à l’aide de pthread, tout en assurant une interface utilisateur fluide grâce à ncurses.
</Text>

<Text align="justify">
Le projet repose sur un modèle thread-par-client pour gérer la communication en temps réel, complété par un thread pool côté serveur pour les opérations asynchrones.  
L’interface Ncurses offre une gestion fine du terminal (curseur, couleurs, rafraîchissement de zones) et rend l’expérience fluide malgré la nature textuelle de l’application.
</Text>

## Conception et décisions clés

### Threads POSIX pour la concurrence
<Text align="justify">
Chaque client connecté dispose d’un thread dédié, assurant un traitement parallèle des messages.  
Ce choix garantit la réactivité de la communication, même en présence de plusieurs utilisateurs actifs.
</Text>

### Thread pool pour les tâches asynchrones
<Text align="justify">
Le serveur utilise un pool fixe pour exécuter les tâches longues comme la sauvegarde JSON.  
Cela limite la création et la destruction répétée de threads, améliorant la stabilité sous charge.
</Text>

### Mode pause avec Ctrl+C
<Text align="justify">
Lorsqu’un utilisateur rédige un message, un signal SIGINT déclenche un mode pause.  
Les messages reçus sont stockés dans un buffer circulaire et affichés après l’envoi, évitant les interruptions visuelles.
</Text>

### Interface Ncurses
<Text align="justify">
Ncurses a été utilisée pour contrôler le rendu terminal : affichage multifenêtre, curseur visible, gestion des couleurs et de la barre d’état (heure, pseudo, statut).
</Text>

## Résultats obtenus

<Text align="justify">
Le projet a permis d’obtenir une application robuste et agréable à utiliser en mode terminal.  
L’approche modulaire (client, serveur, common) facilite l’évolution du code et l’ajout de futures fonctionnalités comme l’authentification ou le chiffrement.  
Le mode pause et la sauvegarde asynchrone illustrent la combinaison entre ergonomie et performance dans un environnement purement C.
</Text>
