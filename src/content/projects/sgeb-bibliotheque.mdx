## Introduction

**SGEB** is a desktop application designed to manage all the operations of a library: documents, members, loans, returns and penalties.
Built as part of the **MIAGE Master's — Paris Dauphine / PSL University**, this project demonstrates a modern, robust and scalable architecture combining **JavaFX (MVVM)**, **Domain-Driven Design (DDD)** and **Hexagonal Architecture**.

<Callout tone="brand">
The project emphasises strict separation of responsibilities, testability of the domain and ease of technical evolution.
</Callout>

## Software architecture

The application is built on a **hexagonal architecture** organised in three autonomous layers.
This organisation isolates business logic, makes it easy to swap technologies (database, API, UI) and ensures strong testability.

### 1. Domain (`application.domain`)
- Rich entities: *Loan*, *Document*, *Member*, *Penalty*
- Value objects: *Money*
- Policies: loan duration, penalty calculation, loan limit
- Ports: interfaces for repositories and external services
- Application services: orchestration of use cases

### 2. Infrastructure (`application.infrastructure`)
- SQLite repositories
- OpenLibrary API adapters
- Local storage of cover images

### 3. User interface (`application.ui`)
- JavaFX based on the **MVVM** pattern
- FXML views + ViewModels + Controllers
- Centralised navigation

## Data model

The SQLite database uses a simple, consistent model.

- Main tables: **PERSON**, **DOCUMENT**, **LOAN**, **PENALTY**
- TPH inheritance (discrimination through `dtype` for Book, Magazine, CD)
- Integrity constraints enabled (foreign keys)

## Limitations and future improvements

### Current limitations
- Simplified password security
- No user session expiry
- Single-user mode because of SQLite

### Planned improvements
- Move to PostgreSQL
- Reservation system
- CSV / Excel export
- Email sending through a NotificationPort
- Barcode integration

## Conclusion

**SGEB** is a complete demonstration of modern software design: hexagonal architecture, separation of responsibilities, a DDD approach, an elegant JavaFX interface and a smooth user experience.
